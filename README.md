# HealthAI — AI-Driven Personal Health Platform

HealthAI is a full-stack healthcare platform designed to help users **understand, track, and manage their personal health information from a single interface**.

Built for the **Healthcare Hackathon 2025**, the project combines symptom analysis, health tracking, medication adherence, medical report analysis, emergency support, and conversational AI into one Flask-based application.

> **Note:** HealthAI is an educational/demo project and is not a substitute for professional medical diagnosis or treatment.

---

## 🎯 Problem

Personal health information is often scattered across prescriptions, medical reports, medications, symptom history, and appointments.

This creates several practical problems:

* Users may not have a clear view of their overall health history.
* Symptoms are often recorded inconsistently or not recorded at all.
* Medication adherence is difficult to track over time.
* Medical reports can contain technical information that is difficult for non-medical users to understand.
* Important health patterns can be missed when information is stored in separate places.
* During emergencies, critical health information may not be immediately accessible.

### Our Approach

HealthAI brings these activities into one platform and connects the data generated by each feature.

```text
Symptoms ─────────┐
Medications ──────┤
Reports ──────────┤
Health Profile ───┼──► Health Data ──► Insights
Appointments ────┤
Chatbot ──────────┘
                         │
                         ▼
                    Dashboard
```

The goal is not to replace doctors, but to provide users with a **centralized health-management and decision-support platform**.

## ✨ Key Features

### 🏠 Health Dashboard

The dashboard acts as the central hub for the user's health information.

* Overall health score
* Health score history and trend
* Medication adherence summary
* Recent symptoms
* Health alerts
* AI-generated/pattern-based health insights
* Upcoming appointments
* Quick actions for common tasks

The dashboard aggregates information from multiple database entities rather than maintaining a separate copy of the user's health data.

---

### 🩺 Health Check

Health Check combines symptom analysis and medical report analysis.

#### Symptom Checker

Users can enter symptoms and receive:

* Possible condition mapping
* Condition probability/scoring
* Urgency classification
* Health guidance
* Structured symptom logging

The symptom-analysis model uses a **TF-IDF vectorizer and Logistic Regression model** trained on the project's symptom dataset.

```text
User Symptoms
      ↓
Text Processing
      ↓
TF-IDF Vectorization
      ↓
Logistic Regression
      ↓
Condition Prediction
      ↓
Urgency / Guidance
      ↓
SymptomLog
```

#### Report Analyzer

Users can upload medical reports and receive:

* Extracted health metrics
* Normal / borderline / abnormal classification
* Metric-level analysis
* AI-assisted interpretation
* Stored report analysis for later reference

---

### 💊 Medication Management

HealthAI provides medication tracking and adherence monitoring.

Users can:

* Add medications
* Specify dosage and frequency
* Set medication timing
* Track taken/missed doses
* View daily medication status
* Monitor 7-day adherence
* View longer-term adherence percentages
* Identify adherence patterns

Medication activity contributes to the platform's health insights and health-score calculations.

### 🤖 AI Health Assistant

HealthAI includes a conversational health assistant available throughout the authenticated application.

The chatbot uses a **hybrid architecture**:

```text
                     User Message
                          │
                 Local classification
                          │
          ┌───────────────┼────────────────┐
          ▼               ▼                ▼
       Basic          Emergency       Meaningful
       Chat              │             Message
          │              │                │
     Local Reply    Immediate Safety    Gemini
                                           │
                                   ┌───────┴───────┐
                                   ▼               ▼
                               General        Personal Health
                               Question          Message
                                                  │
                                                  ▼
                                             SymptomLog
```

#### Local handling

Common interactions such as greetings, acknowledgements, and basic conversation are handled locally without calling Gemini.

Emergency messages are also detected locally so the safety response does not depend on an external AI request.

#### Gemini-powered conversations

Meaningful messages are sent to Gemini for natural-language understanding and response generation.

For personal health messages, the structured Gemini response can extract:

* Symptoms
* Duration
* Explicitly stated severity
* Urgency level

This information can then be stored as a `SymptomLog`.

For example:

```text
"What is fever?"
        ↓
ChatLog

"I've had fever and headache since yesterday."
        ↓
ChatLog + SymptomLog
```

The system does not create symptom records for general questions about diseases or symptoms.

## 🧠 Health Insights

HealthAI maintains a dedicated health-insights layer that analyzes information already stored in the platform.

The current implementation is **rule-based and data-driven**, using:

* Medication adherence
* Recent symptoms
* Symptom severity
* Health-score trends
* Medical report abnormalities
* Changes in report values

The system can identify patterns such as changes in medication adherence, increased symptom activity, or changes in health metrics.

```text
MedicationLog ─────┐
SymptomLog ────────┤
HealthScore ───────┼──► Health Insights ──► Dashboard
ReportLog ─────────┘
```

This architecture also allows the insights engine to evolve into a more advanced AI-assisted system in the future.

---

## 🏥 Health Score

The dashboard generates a health score using multiple health signals.

The current calculation considers:

* Medication adherence
* BMI
* Symptom history/load

The score is stored historically so that users can observe changes over time rather than viewing only a single number.

## 🗄️ Database

HealthAI uses **SQLAlchemy** for database interaction.

### Main entities

| Table             | Purpose                                     |
| ----------------- | ------------------------------------------- |
| `users`           | Authentication and personal health profile  |
| `symptom_logs`    | Structured symptom and health-event history |
| `medications`     | Medication information                      |
| `medication_logs` | Daily medication adherence                  |
| `report_logs`     | Medical report analysis records             |
| `documents`       | User health documents                       |
| `health_scores`   | Historical health scores                    |
| `appointments`    | Appointment information                     |
| `chat_logs`       | Complete chatbot conversation history       |

### Chat vs Health Data

A deliberate distinction is maintained between conversation history and structured health information:

```text
ChatLog
   │
   └── Stores every chatbot interaction

SymptomLog
   │
   └── Stores meaningful personal health information
```

This allows the chatbot to maintain a complete conversation record without treating every health-related question as a personal medical record.

## 🔐 Environment Variables

Gemini-powered chatbot functionality requires:

```env
CHATBOT_GEMINI_ENABLED=true
CHATBOT_GEMINI_API_KEY=your_api_key_here
```

Other AI/report-analysis configuration is kept in environment variables and should **never be committed to Git**.

Create a local `.env` file for development.

> `.env` is included in `.gitignore` and is intentionally not part of this repository.

## 🚀 Getting Started

### Prerequisites

* Python 3.9+
* pip
* Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Sanchit-Patil08/HealthAI.git

cd HealthAI

# Create a virtual environment
python -m venv venv

# Activate it
# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Environment Setup

Create a `.env` file in the project root and add the required configuration:

```env
CHATBOT_GEMINI_ENABLED=true
CHATBOT_GEMINI_API_KEY=your_api_key_here
```

### Run

```bash
python app.py
```

Then open:

```text
http://localhost:5000
```

## ⚠️ Safety & Limitations

HealthAI is designed as a **health-management and decision-support application**, not as an autonomous medical system.

The AI assistant:

* Does not provide confirmed diagnoses.
* Does not prescribe medication.
* Does not instruct users to start or stop medication.
* Uses structured information extraction for symptom logging.
* Directs potentially serious situations toward professional medical attention.

Some components are intended for demonstration rather than clinical deployment. Production use would require appropriate medical validation, security review, privacy controls, infrastructure hardening, and regulatory compliance.
